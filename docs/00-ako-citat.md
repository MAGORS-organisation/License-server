# 0. Ako čítať tento dokument

> Časť zadania **Symbolon — licenčný server na .NET 10**. Späť na [obsah](README.md) · [prehľad projektu](../README.md).

Dokument je napísaný ako reťaz štyroch rolí, tak ako si žiadal:

1. **Architekt** — kapitoly 4–7 (doménový model, formát licencie, architektúra, floating protokol)
2. **Programátor** — kapitola 8 (referenčná implementácia v .NET 10)
3. **Bezpečák** — kapitola 9 (threat model, PQC stratégia, supply chain)
4. **Tester** — kapitola 10 (testovacia stratégia, unit + aplikačné testy)

Kapitoly 1–3 sú produktové a **kapitola 1.0 je zámerne nepríjemná**. Prečítaj si ju prvú. Ak ťa neprekoná, zvyšok dokumentu je použiteľný ako inžinierske zadanie. Ak ťa prekoná, ušetril si ~150 človekodní.
